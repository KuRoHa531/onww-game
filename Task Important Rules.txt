役職を追加するときは、役職の並びを揃えるために次の2つを必ずやってください。
 1. js/roleorder.js の ONW.ROLE_ORDER の末尾に、新しい役職のIDを足す(wikiの順=実装した順)。あわせて wiki/js/wiki-data.js の order も、同じ並びで末尾の次の番号にする。
 2. 役職ファイルの groups の数字は「所属」を表すだけで、並びには使われない。並びを直したいときは groups の数字ではなく、ROLE_ORDER を直す。
 変化先・変化公開・COボタン・ロビー・ガイド・デバッグの並びは、すべて ONW.ROLE_ORDER で決まる(新しい場所で役職を並べるときも ONW.sortByRoleOrder(ids) を通すこと)。
 確認: node _wip/orderAll.js .(全部 OK になること)。
 ※ ONW.ROLE_INFO のキー順は起床順が同じ役職の先後に使われるので、並べ替えないこと。js/settings.js の ROLES_V*(ルールコード)も、並びを変えないこと。

夜・朝のうちの能力で ONW.observeNote を呼ぶ役職を足す(移植する)ときは、その役職の info に observe: "player"(墓地だけが対象なら "grave")を足してください。詩人・観測の人狼の闇鍋シナジーの対象が自動で増えます。あわせて wiki/js/synergy-data.js の控えも直し、node _wip/observeSynergyCheck.js . で確認(詳細は docs/observe-synergy.md)。

マイクラ版の封印の対象(YAMINABE_SEAL_TARGET_ROLES)に入っている役職を足す(移植する)ときは、その役職の info に sealTarget: true を足してください。封印の狂人のシナジー(封印作用のある役職)の対象が自動で増えます。あわせて wiki/js/synergy-data.js の控えも直し、node _wip/sealTargetCheck.js . で確認(詳細は docs/seal-target.md)。

【納品のタイミング（最重要・必ず守る）】
各ステップ（1of4 / 2of4 / 3of4 / 4of4）が終わったら、そのステップの zip と依頼文テキストを「その場で」present_files で納品してから、次のステップに進むこと。
 ・「全部終わってから分割ファイルをまとめて納品する」のは禁止。途中で利用制限に当たっても、終わったステップ分が必ず手元に届くようにするため。
 ・ファイルを書き出しただけでは納品にならない。present_files を呼んで初めて納品。ステップごとに必ず呼ぶ。
 ・前のステップの納品ファイルを、次のステップの作業中に消さない・上書きしない（出力フォルダの掃除で消さない）。各ステップの zip は、そのステップの完了時点の内容のまま残す。
 ・手順の型: ステップN の実装 → 確認 → zip と依頼文を出力フォルダへ → present_files で納品 → 「ステップN を納品した」と報告 → ステップN+1 へ。
 ・最後に全体 zip を納品する（作業を途中で止めるときも全体 zip を納品する）。
 ・zip には minecraftver.mcpack を必ず入れる（除外しない）。
